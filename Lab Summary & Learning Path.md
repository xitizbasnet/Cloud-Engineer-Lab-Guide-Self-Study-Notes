# Lab Summary & Learning Path

> [!IMPORTANT]
> This learning path is designed to progressively develop the skills required for a **Cloud Engineer**, **Linux Administrator**, **Azure Administrator**, **DevOps Engineer**, and **Infrastructure Engineer**. Each lab builds upon concepts introduced in previous labs, providing a structured progression from foundational administration to advanced cloud, automation, and security topics.

---

# 📋 Learning Path Overview

| **Lab** | **Topic** | **Level** | **Estimated Duration** | **Key Skills** |
|:--------:|-----------|-----------|:----------------------:|----------------|
| **LAB 01** | Linux Multi-Distro Administration | Beginner | 2–3 Hours | RHEL, Ubuntu, Windows Server |
| **LAB 02** | DNS, DHCP & IPAM | Intermediate | 2–3 Hours | BIND, ISC-DHCP, phpIPAM |
| **LAB 03** | Infoblox Migration | Advanced | 3–4 Hours | ASR, GMC, BCDR, ATC, RPZ |
| **LAB 04** | Azure Compute & Networking | Intermediate | 3–4 Hours | Virtual Machines, Virtual Networks (VNet), AKS, ACR, Azure Budget |
| **LAB 05** | Azure AD & Migrations | Intermediate | 2–3 Hours | Azure AD Connect, GSS-TSIG, Amazon Route 53 |
| **LAB 06** | Azure Business Continuity & Disaster Recovery (BCDR) | Intermediate | 2–3 Hours | Azure Site Recovery (ASR), Azure Backup, RTO/RPO |
| **LAB 07** | Docker & Kubernetes on Azure/AWS | Advanced | 3–4 Hours | Docker, Podman, Buildah, AKS, Amazon EKS, CNI, IPAM |
| **LAB 08** | Automation – Bash, PowerShell & APIs | Intermediate | 2–3 Hours | Bash, PowerShell, Azure CLI, Azure Cost Management API |
| **LAB 09** | Linux Server Administration (Tier I–III) | Intermediate | 3–4 Hours | LVM, RAID, Samba, NFS, Apache, KVM, IPTables |
| **LAB 10** | OS Hardening, Networking & Performance | Advanced | 2–3 Hours | Lynis, Firewall, NAT, DMZ, Performance Tuning, Knowledge Base Writing |
